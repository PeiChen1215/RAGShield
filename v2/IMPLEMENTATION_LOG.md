## 遗留问题与局限性

1. 事实篡改漏报: atk_poi_004（公司地址变更）属于非数值事实篡改，当前规则+LLM均未能检测
2. 多文档组合攻击: 当前架构未实现跨文档攻击链检测
3. LLM 判断不一致性: 相同输入多次调用 LLM 可能给出不同评分
4. Extractor 模糊语义: 描述危险流程的事实 vs 正常安全策略事实难以完全区分
5. 延迟: 完整版端到端延迟约 3~5 秒（含多次 LLM 调用），轻量版 < 500ms
