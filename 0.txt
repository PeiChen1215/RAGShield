一、项目概述
RAGShield：基于多维度异常检测的 RAG 系统知识库安全智能防护系统
1.1 项目简介
随着 ChatGPT、DeepSeek、通义千问等大语言模型的广泛应用，检索增强生成
（RAG）技术已成为企业构建 AI 应用的主流方案。RAG 通过将大模型与外部知识库结
合，有效解决了模型幻觉问题，提升了回答的准确性和时效性。然而，RAG 系统面临
严重的知识库投毒攻击威胁——攻击者通过在知识库中注入恶意文档，可诱导大模型
输出错误信息、泄露敏感数据或执行恶意指令。
本项目针对这一新兴安全挑战，创新性地提出三层多维异常检测架构，整合知识
库离群文档检测、检索过程监控、生成内容验证三种前沿技术，构建面向 RAG 系统的
智能安全防护系统。与现有方案相比，本系统在投毒检测准确率（目标≥90%）、误报
率控制（目标≤5%）和检测延迟（目标<150ms）三个维度实现全面提升，并首次针对
中文 RAG 场景进行专项优化，支持知识库离群文档检测、查询-文档相关性异常分析、
检索-生成一致性验证等核心功能。

3.2 创新点二：知识库离群文档检测
借鉴异常检测和无监督学习思想，构建基于嵌入空间分析的离群文档检测机制。
通过分析文档向量在嵌入空间中的分布特征，识别与正常文档聚类明显偏离的异常文
档，实现投毒文档的预防性发现。采用 Isolation Forest 和 LOF（局部离群因子）算
法，结合文档主题一致性分析，有效识别恶意注入文档。
10
3.2.1 离群检测算法伪代码
def detect_outlier_documents(knowledge_base, threshold=0.1):
# Step 1: 文档嵌入
embeddings = [embed(doc) for doc in knowledge_base]
# Step 2: Isolation Forest 检测
clf = IsolationForest(contamination=threshold)
outlier_labels = clf.fit_predict(embeddings)
# Step 3: LOF 验证
lof = LocalOutlierFactor(n_neighbors=20)
lof_scores = lof.fit_predict(embeddings)
# Step 4: 综合判定
suspicious_docs = []
for i, (iso_label, lof_label) in enumerate(zip(outlier_labels, lof_scores)):
if iso_label == -1 and lof_label == -1:
suspicious_docs.append(knowledge_base[i])
return suspicious_docs 算法 1：知识库离群文档检测算法
3.2.2 嵌入空间可视化
正常文档在嵌入空间中形成紧密的聚类，而恶意文档由于语义异常，往往分布在
聚类边缘或形成独立的离群点。
3.3 创新点三：注意力方差异常分析
针对检索过程中的异常行为，引入注意力方差分析机制。通过监控查询-文档注意
力权重的分布特征，识别注意力分布异常（过于集中或过于分散）的可疑检索结果，
有效检测投毒攻击。受 AV Filter 论文启发，注意力方差可有效区分正常检索和恶意
检索模式。
11
3.3.1 注意力方差计算
注意力方差计算公式：
def calculate_attention_variance(query_embedding, doc_embeddings):
# 计算查询-文档注意力权重
attention_weights = softmax(
[cosine_similarity(query_embedding, doc_emb)
for doc_emb in doc_embeddings]
)
# 计算注意力方差
attn_mean = np.mean(attention_weights)
attn_variance = np.var(attention_weights)
# 计算注意力熵
attn_entropy = -np.sum(attention_weights * np.log(attention_weights + 1e-10))
# 异常判定
is_anomaly = (attn_variance > VARIANCE_THRESHOLD or
attn_entropy < ENTROPY_THRESHOLD)
return is_anomaly, attn_variance, attn_entropy
算法 2：注意力方差异常检测
3.3.2 注意力分布特征
正常检索的注意力分布相对均匀，而投毒攻击往往导致注意力过度集中于恶意文
档，形成异常的方差峰值。
3.4 创新点四：检索-生成一致性验证
针对生成内容的可靠性验证，设计检索-生成一致性检测机制。通过对比检索到的
参考内容与模型生成内容的语义一致性，识别生成内容是否被恶意文档污染，确保输
出结果的可信度。采用 NLI（自然语言推理）模型判断生成内容是否被检索内容所支
持。

def verify_retrieval_generation_consistency(retrieved_docs, generated_text):
# Step 1: 检索内容聚合
retrieved_content = " ".join([doc.text for doc in retrieved_docs])
# Step 2: NLI 模型判断
# entailment: 生成内容被检索内容支持
# contradiction: 生成内容与检索内容矛盾
# neutral: 无法判断
nli_result = nli_model.predict(
premise=retrieved_content,
hypothesis=generated_text
)
# Step 3: 语义相似度
gen_embedding = embed(generated_text)
retrieved_embedding = embed(retrieved_content)
semantic_sim = cosine_similarity(gen_embedding, retrieved_embedding)
# Step 4: 综合判定
if nli_result == 'contradiction' or semantic_sim < SIM_THRESHOLD:
return False, 'Inconsistent with retrieved content'
return True, 'Consistent' 算法 3：检索-生成一致性验证

4.3 检测流程伪代码
RAGShield 完整检测流程如下：
def ragshield_detect(query, knowledge_base, rag_pipeline):
# ========== Layer 1: 知识库层检测 ==========
suspicious_docs = detect_outlier_documents(knowledge_base)
if len(suspicious_docs) > 0:
log_warning(f"Found {len(suspicious_docs)} suspicious documents")
# ========== Layer 2: 检索层检测 ==========
query_embedding = embed(query)
retrieved_docs = rag_pipeline.retrieve(query, top_k=5)
# 注意力方差分析
doc_embeddings = [embed(doc) for doc in retrieved_docs]
is_anomaly, var, entropy = calculate_attention_variance(
query_embedding, doc_embeddings
)
if is_anomaly:
retrieval_risk_score = 0.8
else:
retrieval_risk_score = 0.2
# ========== Layer 3: 生成层检测 ==========
generated_text = rag_pipeline.generate(query, retrieved_docs)
is_consistent, reason = verify_retrieval_generation_consistency(
retrieved_docs, generated_text
)
if not is_consistent:
generation_risk_score = 0.9
else:
generation_risk_score = 0.1
# ========== 综合评分 ==========
final_risk_score = weighted_fusion(
knowledge_risk=0.3 if suspicious_docs else 0.0,
retrieval_risk=retrieval_risk_score,
generation_risk=generation_risk_score
)
return {
'risk_score': final_risk_score,
'is_safe': final_risk_score < 0.5,
'details': {
'suspicious_docs': suspicious_docs,
'attention_variance': var,
'consistency_check': is_consistent
}
}

4.4.2 异常评分融合
三层检测结果的加权融合策略：
def weighted_fusion(knowledge_risk, retrieval_risk, generation_risk):
# 动态权重调整
weights = {
'knowledge': 0.3, # 知识库层权重
'retrieval': 0.3, # 检索层权重
'generation': 0.4 # 生成层权重（最高）
}
# 加权融合
final_score = (
weights['knowledge'] * knowledge_risk +
weights['retrieval'] * retrieval_risk +
weights['generation'] * generation_risk
)
return min(final_score, 1.0) # 限制在[0,1]范围内
